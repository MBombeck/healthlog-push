# Continuity

healthlog-push has one maintainer. This page states what is in place for the case that the maintainer can
no longer look after the project.

- A continuity arrangement exists. A trusted contact designated by the maintainer holds sealed emergency
  access.
- A successor is set for the maintainer's GitHub account, which owns this repository.
- The arrangement is reviewed at least once a year.

Nothing else about the arrangement is published. The roles of the project are described in
[GOVERNANCE.md](../GOVERNANCE.md).
